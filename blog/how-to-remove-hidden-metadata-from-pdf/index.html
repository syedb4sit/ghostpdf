How to Inspect and Scrub Hidden Metadata from PDFs

Check Author, Creator, Title, and Keywords tags inside exported PDFs and clear identifying details before sharing publicly.

1. What Invisible Data Lives Inside Exported PDFs (Author Names, Software, Timestamps)

Whenever Microsoft Word, Google Docs, macOS Preview, or Adobe Acrobat exports a document, it quietly embeds an Info metadata dictionary inside the PDF trailer. Without checking properties, files you circulate to clients or opposing counsel often broadcast your personal computer login (John.Smith-MacBook), original working draft filenames (Proposal_CompetitorQuote_v2), corporate software versions, and internal keywords.

Blindly sharing un-audited PDFs compromises anonymous peer reviews, leaks internal agency contractor names, and exposes client tracking crumbs. Inspecting and wiping metadata takes under ten seconds locally before public posting.

2. Auditing and Scrubbing Hidden PDF Properties Locally

  1. Load Your Finished PDF Into PDF Metadata: Open PDF Metadata and drop any resume, whitepaper, press kit, or legal filing.
  2. Inspect Every Exposed Field Carefully: Review existing values populated across Title, Author, Subject, Creator, Producer, and Keywords.
  3. Wipe or Overwrite Sensitive Identifiers: Clear identifying personal usernames or sensitive project strings—or rewrite Title cleanly for public browser tabs and brand alignment.
  4. Save Scrubbed File & Inspect Fresh Properties: Download the cleaned PDF cleanly, then verify inside browser/system file properties that stale details disappeared completely.

4. Complete Sanitization Checklist for Sensitive Releases

  • Metadata Scrubbing Does Not Erase Visual Page Text: Always remember PDF Metadata wipes document properties—to strip private phone numbers, client names, or dollar amounts *printed inside pages*, burn pixel redactions in Redact PDF.
  • Re-Check Metadata After Every Subsequent Tool Step: Make PDF Metadata the very last polish after merging, watermarking, or compressing so downstream saves don't leave generic Producer values you didn't intend.
  • Flatten Annotations Too If Needed: Review comments or sticky notes carried from desktop editing tools also expose reviewer usernames—strip interactive widgets via Flatten PDF or pixel redaction.
