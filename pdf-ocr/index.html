How to Use PDF OCR

1. Upload Scanned PDF or Image

Select any scanned PDF, receipt photo, or PNG/JPG screenshot.

2. Pick Language & Run OCR

Choose the document language and click Run Browser OCR to recognize text locally via Tesseract WebAssembly.

3. Copy or Download TXT

Copy the recognized text directly or export it as a clean .txt file.
